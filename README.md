# Student Expense Tracker

## 📌 Project Overview

Student Expense Tracker is a simple Java-based application designed to help students manage their daily expenses. It provides a menu-driven command-line interface where users can record expenses, view them, calculate total spending, see category-wise summaries, and delete expenses.

The project is developed using basic Java programming concepts and is suitable for beginners.

## 🎯 Objectives

* To provide a simple way to record daily expenses.
* To calculate and display total spending.
* To organize expenses into different categories.
* To help users understand their spending habits.
* To practice Java programming and data structures.

## ✨ Features

* Add a new expense
* View all expenses
* Calculate total expenses
* View category-wise expense summary
* Delete an expense
* Simple menu-driven interface
* Easy to use and run

## 🛠️ Technologies Used

* **Language:** Java
* **Interface:** Command Line Interface (CLI)
* **Data Structures:** ArrayList, HashMap
* **Compiler:** Java JDK

Before running the project, make sure Java is installed on your computer.

```bash
java -version
```

You can use any Java version that supports the code.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd Student-Expense-Tracker
```

### 3. Compile the program

```bash
javac Main.java
```

### 4. Run the program

```bash
java Main
```

## 🖥️ How It Works

After starting the program, a menu is displayed:

```text
===== STUDENT EXPENSE TRACKER =====
1. Add Expense
2. View Expenses
3. Total Expense
4. Category Summary
5. Delete Expense
6. Exit
```

The user can select an option by entering its number.
